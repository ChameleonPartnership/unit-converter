# Unit Converter Web App

A dependency-free, responsive unit converter built with HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` - main converter
- `about.html` - tool explanation
- `privacy.html` - privacy policy suitable for ad-supported sites
- `terms.html` - standard terms of use

## Features

- Temperature, length, weight, volume, pressure, speed, and area conversions
- Real-time two-way calculation
- Recent conversion history stored in localStorage
- Dark mode stored in localStorage
- Copy and share actions
- Semantic HTML, ARIA labels, keyboard-friendly controls
- Ad placement placeholders above, below, and beside the calculator

## Deployment

This is a static site. Deploy the repository root to Vercel, GitHub Pages, Netlify, or any static hosting provider.

For Vercel, no build command is required.
